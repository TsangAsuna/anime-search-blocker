# 动漫花园 / 蜜柑动画 / Nyaa 搜索结果屏蔽器

一个油猴（Tampermonkey / Violentmonkey）用户脚本：在 **动漫花园**、**蜜柑动画**、**Nyaa** 及其镜像站的搜索结果 / 资源列表中自动屏蔽指定制作组的资源行，并支持在页面上自定义添加、删除屏蔽规则。

## 支持的站点（v1.2.0）

脚本按**页面结构**自动识别站点，主站与镜像通用：

| 站点 | 域名 | 屏蔽位置 |
| --- | --- | --- |
| 动漫花园（原站） | `share.dmhy.org` | 资源列表每一行 |
| 动漫花园（镜像） | `animes.garden` | 资源列表每一行 + 顶部「字幕组」筛选下拉项 |
| 蜜柑动画（主站） | `mikanani.me`、`mikanime.tv` | 搜索结果每一行种子 |
| 蜜柑动画（镜像） | `mikan.makura.cc`、`mikanani.kas.pub` | 同上（结构与主站一致，已实测） |
| Nyaa（主站） | `nyaa.si`、`sukebei.nyaa.si` | 种子列表每一行（含搜索、分类、用户页） |
| Nyaa（镜像） | `nyaa.land`、`nyaa.help`、`sukebei.nyaa.help` | 同上（结构与主站一致，已实测） |

> 说明：nyaa.best 等失效域名（已被接管跳转）未收录；后续出现新镜像时，只要结构相同，在脚本管理器里给脚本加一行 `@match https://新域名/*` 即可生效，无需改代码。

## 默认屏蔽

- `DBD` —— 同时命中 DBD-Raws、DBD制作组 等
- `Nix-raws` —— 默认忽略大小写，同时命中 Nix-Raws
- `沸班亚马制作组`

匹配规则：资源行的**标题或制作组名称**包含任一关键词（不区分大小写）即整行隐藏。关键词是普通文字匹配，不是正则表达式。在 Nyaa 上组名同样是标题开头的 `[组名]` 前缀，因此照常生效。

### 深度屏蔽（v1.2 新增，默认开启）

隐藏行的同时，把该行内的**磁力链接、.torrent 下载链接、keepshare/pikpak 链接、复制磁力用的剪贴板文本**一并清空（原值暂存，取消屏蔽时自动还原）。效果：

- 网页上任何"复制全部磁力"类功能（包括遍历 DOM 的第三方脚本）都无法从被屏蔽行拿到链接
- 正常行、未屏蔽行完全不受影响
- 关掉开关后恢复为纯视觉隐藏

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey 扩展
2. 打开本文件夹中的 `anime-search-blocker.user.js`（直接双击，或把文件拖到浏览器里）
3. 在脚本管理器弹出的安装页点击「安装」

## 使用

- 安装后打开上述站点的搜索结果或资源列表页，命中的行会被自动隐藏
- 页面 **右下角 🚫 按钮**：红点数字 = 当前页面已屏蔽的条目数；点击按钮打开设置面板
- 也可以点击浏览器工具栏中的脚本管理器图标 →「屏蔽规则设置」打开面板

### 设置面板说明

| 选项 | 说明 |
| --- | --- |
| 启用屏蔽 | 总开关，取消勾选后所有行恢复显示 |
| 屏蔽关键词（文本框） | 每行一条，删掉一行即取消该规则；可填任意文字（组名、标题片段、Q群号等） |
| 快速添加 | 输入关键词回车或点「添加」，自动保存并立即生效 |
| 忽略大小写 | 勾选后 `nix-raws` 也能匹配 `Nix-Raws`（默认勾选） |
| 深度屏蔽 | 同时清空被屏蔽行的磁力/种子/keepshare 链接和剪贴板文本，防止任何复制方式带走（默认勾选） |
| 同时隐藏「字幕组」筛选下拉条目 | 动漫花园（animes.garden）顶部导航的字幕组筛选菜单里，被屏蔽组的入口也一并隐藏（默认勾选） |
| 在按钮上显示屏蔽计数 | 控制右下角红色数字徽标（默认勾选） |
| 保存并应用 | 把文本框和勾选项写入浏览器本地存储并立即生效 |
| 立即扫描 | 规则未变、只是想刷新一次屏蔽状态时用 |
| 恢复默认 | 一键恢复到出厂的三条关键词和选项 |

## 常见问题

**为什么设置不能同步到其他电脑？**
规则保存在浏览器本地（Tampermonkey 的存储），换电脑/换浏览器需要重新设置一遍。

**翻页、切换筛选后又出现了？**
脚本内置了页面变化监听，会自动重新屏蔽；如果个别情况漏掉，点「立即扫描」即可。

**新出了一个镜像站，怎么支持？**
在 Tampermonkey 编辑该脚本，在头部元数据块加一行 `https://镜像域名/*` 形式的 `@match`，保存即可。识别靠页面结构，不依赖域名。

**想屏蔽某个组但不想屏蔽标题里带同样文字的正常资源？**
当前版本按整行文字匹配，简单可靠。如果误伤，可以把关键词写得更具体，例如把 `DBD` 改成 `DBD-Raws` 或 `DBD制作组`。

**蜜柑的番剧详情页、动漫花园的首页日历会屏蔽吗？**
不会，本脚本只处理搜索结果 / 资源列表类页面。

**被屏蔽的资源还能通过复制链接拿到吗？**
默认开启的「深度屏蔽」下拿不到：磁力、.torrent、keepshare 链接和剪贴板文本在屏蔽时已被清空，手动复制、右键复制、第三方批量复制脚本都只会得到空值。关闭深度屏蔽后退化为纯视觉隐藏（行隐藏但 DOM 里链接仍在，遍历 DOM 的脚本理论上仍可取到）。注意：「复制 RSS 订阅链接」复制的是订阅地址本身，feed 内容由服务器生成、不含本脚本的过滤，若配合 AutoBangumi 等自动下载，请在那边另配排除规则。
